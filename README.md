## ✨ Overview
Welcome to the official Github repository of **JNY Student Council** Website. This project is a high school scrapbook inspired website designed to showcase events, share blog posts, and provide information about council members. 

## 🔥 Key Features
- 📸 **Dynamic Event Gallery**: Interactive scrapbook-style gallery with parallax effects and category filtering.
- ✍️ **CMS-Powered Blog**: Full-featured blog integrated with **Sanity CMS** for real-time content management.
- 👥 **Member Boards**: Specialized sections for council members, level representatives, and advisors.
- 🚀 **Smooth UX**: Integrated with **Lenis** for buttery-smooth scrolling and **Framer Motion** for state-of-the-art animations.
- 📝 **Interactive Feedback**: A message submission system directly linked to **Google Sheets** for real-time responses.
- 🖱️ **Custom Experience**: Tailored custom cursor and interactive UI elements for a unique feel.

## 🚀 Getting Started

### 1️⃣ Prerequisites
- **Node.js** (LTS version)
- **npm** or **bun**
- **Sanity Project ID**
- **Google Cloud Service Account** (for message submissions)
